# FactorAlpha+ Earnings Prep

Opinionated earnings prep workflow using Next.js, Supabase, and Anthropic agents.

## Setup

1. Copy `.env.local.example` to `.env.local` and fill in values.
2. Create a Supabase project and run `supabase/schema.sql`.
3. Configure Anthropic agents (if you have API access).
4. Run `npm install` then `npm run dev`.
